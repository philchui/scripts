# Scripts

A collection of small scripts I use to practice automation, system administration, and security tasks.

## Languages

- **PowerShell** – Windows automation, system info, log collection  
- **Python** – Parsing logs, simple tools, experiments  
- **Bash** – Basic Linux automation

## Structure

- `powershell/` – `.ps1` scripts and examples  
- `python/` – `.py` scripts  
- `bash/` – Shell scripts  

Each subfolder has its own README with usage examples.
